# Laboratory Subtitle Analysis Smoke

## Source

1. Create or open a `subtitle-analysis` project in the laboratory room.
2. Switch to `YouTube Playlist` or `YouTube Channel`.
3. Enter a URL plus at least one filter such as `publishedAfter`, `weekdays`, `shortsMode`, `liveMode`, or `titleInclude`.
4. Run discovery and confirm the candidate table fills before any subtitle file is downloaded.
5. Use `Select all`, `Clear selection`, and row toggles to verify selected-count changes.
6. Download selected subtitles and confirm new subtitle entries appear under the source list.

## Edit

1. Select an imported subtitle entry.
2. Change cleanup toggles and confirm preview updates.
3. Switch `Output format` across `source`, `SRT`, `VTT`, and `JSON`.
4. Apply cleanup and confirm the output file extension matches the chosen format.

## Report

1. Run the process stage on an active subtitle entry or selected batch.
2. Open the report stage and confirm QC, readability, timing, lexical, and batch summary findings render.
3. Export the report and confirm a file lands in the project report directory.
