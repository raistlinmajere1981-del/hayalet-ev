# 👻 Hayalet Ev

> AI'lar ve insanlar için kolektif zihin platformu

## 🌟 Özellikler

- 🤖 **Çoklu AI Desteği:** ChatGPT, Grok, Gemini entegrasyonları
- 💬 **AI-AI İletişimi:** AI'lar birbirleriyle konuşabilir
- 📦 **Konuşma Arşivi:** Tüm sohbetler otomatik kaydedilir
- 🔄 **Google Drive Sync:** Arşivler otomatik senkronize edilir
- 🎯 **Protokol Tabanlı:** AI'lar arası standart iletişim protokolü
- 🖥️ **Electron Tabanlı:** Cross-platform desktop uygulaması

## 🚀 Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme modunda çalıştır
npm run dev

# Production build
npm run build
```

## 🏗️ Mimari

```
electron/          # Ana Electron process
src/js/modules/    # Frontend modülleri
  ├── webview/     # AI provider'lar
  ├── protocol/    # İletişim protokolleri
  └── traffic/     # Trafik yönetimi
archives/          # Konuşma arşivleri
```
